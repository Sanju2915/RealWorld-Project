# Retail Sales Project

This submission is a complete real-world data project in the retail domain.

## Files
- `data/retail_sales_dataset.csv`: custom dataset
- `data/dashboard_data.js`: browser-ready dashboard data
- `analysis_summary.md`: findings, attributes, and conclusion
- `index.html`: visual dashboard

## How to Use
1. Open `index.html` in a browser.
2. Review the summary cards, charts, and sample records.
3. Use `analysis_summary.md` as the written explanation for the project.

## Project Focus
The analysis evaluates sales, profit, customer segments, channels, payment methods, product categories, and regional performance.
